# Skills, Docs & Integrations

> **Layer:** Skills, docs & integrations · **Sources:** `skills/`, `docs/`, `.claude-plugin/`, `.cursor-plugin/`, `.gemini/`, `gemini-extension.json` · **Verified at:** commit afa5622 (2026-06-19)

## Purpose
This layer is the **product surface** that ships in the npm package alongside the server: agent skills (markdown playbooks), end-user documentation, and editor/plugin manifests. Distinguish three kinds of markdown in the repo so they are never confused.

## Three kinds of markdown (do not confuse)

| Kind | Location | Ships to users? | Audience | Editable by hand? |
| ---- | -------- | --------------- | -------- | ----------------- |
| **Shipped skills** | `skills/*/SKILL.md` + `references/` | Yes — `skills` is in package.json `files` | The agent at runtime | Yes (hand-authored) |
| **End-user docs** | `docs/*.md` | Repo/GitHub only (not in `files`) | Humans setting up / debugging | Some yes, some AUTO-GENERATED |
| **This knowledge library** | `.claude/knowledge/**` | No — internal only | Future maintainers/agents documenting the codebase | Yes |

Key point: the `skills/` directory is bundled in the published package (package.json `files: ["build/src", "LICENSE", "skills", ...]`), so skills are a shipped product, not internal notes. Plugin/extension installs (Claude Code plugin, Gemini extension, Copilot plugin-from-source) deliver **MCP server + skills** together; bare `mcp add` / `npx` installs give only the server tools, no skills.

## Key files / dirs
- `skills/` — six shipped agent skills (see [agent-skills.md](agent-skills.md))
- `docs/` — seven end-user docs, two AUTO-GENERATED (see [docs-reference.md](docs-reference.md))
- `.claude-plugin/`, `.cursor-plugin/`, `.gemini/`, `gemini-extension.json` — editor/client integration manifests (see [integrations.md](integrations.md))

## Contents
Index of files in this directory:

## Relationships
- **Depends on / generated by:** `docs/tool-reference.md` and `docs/slim-tool-reference.md` are generated by `scripts/generate-docs.ts` — see [code-generation](../09-build-tooling/code-generation.md).
- **Surfaces:** Skills and docs describe the MCP tools defined in [02-tools](../02-tools/) and the CLI/entrypoints in [01-entrypoints](../01-entrypoints/). The CLI itself (`docs/cli.md`) is generated by `scripts/generate-cli.ts`.

## Gotchas & non-obvious details
- `docs/tool-reference.md` and `docs/slim-tool-reference.md` both start with `<!-- AUTO GENERATED DO NOT EDIT - run 'npm run gen' to update-->`. Never hand-edit them.
- `docs/cli.md` is **not** auto-generated (no header) but documents behavior implemented in `scripts/generate-cli.ts`.
- All four integration manifests pin the version (`1.3.0` / `@1.3.0`) and must be bumped together on release.

## Update triggers
- A new skill is added/removed under `skills/` → update [agent-skills.md](agent-skills.md).
- A new tool or a tool-schema change → `npm run gen` regenerates the tool-reference docs → re-verify [docs-reference.md](docs-reference.md).
- Package version bump → integration manifests change → re-verify [integrations.md](integrations.md).
