## Purpose
Six markdown "skills" shipped inside the npm package (under `skills/`, listed in package.json `files`). Each `SKILL.md` has YAML frontmatter (`name`, `description`) that an agent uses to decide when to load it, then prose workflows that orchestrate the MCP tools. Some carry a `references/` subdir with deeper guides and executable helpers loaded on demand.

## Key files / dirs
- `skills/chrome-devtools/SKILL.md` — general MCP usage (no references)
- `skills/chrome-devtools-cli/SKILL.md` — CLI usage; `references/installation.md`
- `skills/a11y-debugging/SKILL.md` — a11y auditing; `references/a11y-snippets.md`
- `skills/debug-optimize-lcp/SKILL.md` — LCP perf; `references/{elements-and-size,lcp-breakdown,lcp-snippets,optimization-strategies}.md`
- `skills/memory-leak-debugging/SKILL.md` — heap/leak debugging; `references/{common-leaks,memlab}.md` + `references/compare_snapshots.js`
- `skills/troubleshooting/SKILL.md` — connection/setup wizard (no references)

## Gotchas & non-obvious details
- Skills ship in the npm package; only plugin/extension installs deliver them. A bare `claude mcp add ... npx chrome-devtools-mcp@latest` installs the **server only, no skills** (called out in `docs/troubleshooting.md`).
- `chrome-devtools` skill: extension tools require `--categoryExtensions`; memory tools require `--memoryDebugging`. The skill tells the agent to stop and ask the user to reconfigure if the tools are absent.
- `troubleshooting` skill knows the "only 9 tools available" symptom = MCP client enforcing read-only mode (filters tools by `readOnlyHint`); and "Tool not found" can mean `--slim`.
- `memory-leak-debugging` ships an executable Node fallback `compare_snapshots.js` (not just markdown) for when `memlab` is unavailable.
- a11y skill tip: append `.md.txt` to a web.dev article URL to fetch clean raw markdown.

## Update triggers
- A skill is added/removed/renamed under `skills/`, or a `references/` file is added.
- A tool is renamed/added — skill prose references tools by name and can drift.
- A new server flag changes which tools a skill can assume are present.
