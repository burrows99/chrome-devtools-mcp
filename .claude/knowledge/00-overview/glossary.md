# Glossary

> **Layer:** System overview · **Verified at:** commit afa5622 (2026-06-19)

Domain terms used across the codebase and this knowledge library.

| Term | Meaning |
|------|---------|
| **MCP** | Model Context Protocol — the open protocol agents use to call tools. Implemented via `@modelcontextprotocol/sdk`. |
| **MCP client** | The agent-side host (Claude, Cursor, Copilot, Gemini, Antigravity) that launches and talks to this server. |
| **Tool** | A discrete action exposed to the agent (e.g. `navigate_page`, `take_snapshot`). Defined by a [`ToolDefinition`](../02-tools/tool-definition.md). |
| **Slim mode** | `--slim` flag exposing a reduced tool set for basic tasks. See [slim-mode](../02-tools/slim-mode.md). |
| **CDP** | Chrome DevTools Protocol — the wire protocol for controlling/inspecting Chrome. |
| **Puppeteer** | Library that drives Chrome over CDP and auto-waits for action results. |
| **DevTools Frontend** | `chrome-devtools-frontend` — the open-source DevTools UI/engine; a slice is **vendored** here for trace/heap analysis. |
| **Lighthouse** | Google's web performance/quality tool; its engine is vendored for performance insights. |
| **Vendored bundle** | Minified third-party code (DevTools/Lighthouse) regenerated by `scripts/update-lighthouse.ts`; treated as opaque. See [lighthouse-vendoring](../09-build-tooling/lighthouse-vendoring.md). |
| **McpContext** | The central runtime state object (pages, collectors, snapshots, emulation). The hub of the codebase. See [mcp-context](../03-context-state/mcp-context.md). |
| **McpPage** | Per-page wrapper around a Puppeteer page plus its collected data. |
| **McpResponse / SlimMcpResponse** | Builders that assemble token-optimized tool output (text + structured). |
| **Collector** | Per-page gatherer of console / network / service-worker / issue data. See [collectors](../03-context-state/collectors.md). |
| **Snapshot (text/a11y)** | A token-efficient accessibility-tree text view of the page; elements addressed by **UID**. See [text-snapshot](../03-context-state/text-snapshot.md). |
| **UID** | Stable per-element identifier used so the agent can refer to elements across calls. See [utilities/id](../08-utilities/id-string-keyboard.md). |
| **Heap snapshot** | V8 memory snapshot analyzed for leaks (dominators/retainers). See [heap-snapshot-manager](../06-performance-memory/heap-snapshot-manager.md). |
| **Trace** | A recorded Chrome performance trace, parsed into insights. See [trace-processing](../06-performance-memory/trace-processing.md). |
| **CrUX** | Chrome User Experience Report API — real-user field data fetched by performance tools (`--no-performance-crux` to disable). |
| **Clearcut** | Google's logging backend used for anonymous usage statistics. See [telemetry](../07-telemetry/README.md). |
| **Watchdog** | A separate process that flushes telemetry independently of the main server. See [watchdog](../07-telemetry/watchdog.md). |
| **Daemon** | Optional background process backing the CLI. See [daemon](../01-entrypoints/daemon.md). |
| **Third-party developer tools** | A mechanism letting external DevTools extensions expose their own tools through this server. See [third-party-developer](../02-tools/groups/third-party-developer.md). |
| **Eval** | Gemini-driven scenario tests verifying tools are used correctly (`scripts/eval_scenarios`). See [eval-and-metrics](../09-build-tooling/eval-and-metrics.md). |
